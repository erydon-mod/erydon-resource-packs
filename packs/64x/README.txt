ERYDON 64x Resource Pack
========================

Release file: ERYDON-64x-Resource-Pack-compat2-v1.6.0.zip

This is the unified 64x visual pack for ERYDON, ERYDON Themelios and Daedalon.
It works with any compatible subset of those mods and contains detailed
albedo, normal and specular artwork at the mods' stable resource paths.
LabPBR material data is retained where supported.

Compatibility
-------------

- Minecraft 1.20.1 through 1.21.1 resource-pack formats
- Any compatible subset of ERYDON, ERYDON Themelios and Daedalon
- Family compatibility generation 2 (`compat2`)
- Deduplicated ZIPs require a resolver-capable ERYDON family mod build
- Synapheia connected textures are built into compatible ERYDON family mods
- Indium may be needed when Sodium is installed
- A LabPBR-compatible shader is needed for the full material effect

Installation
------------

Place the ZIP in Minecraft's resourcepacks folder and enable it above
general-purpose packs that might override these mods. Do not unzip it.
Use F3 + T to reload resources, or restart Minecraft.

Notes
-----

- Unused mod namespaces are harmless.
- The shared 64x overlay colour, normal and specular set is supplied by the mods.
- Existing OptiFine-format CTM property files are retained byte-for-byte for Synapheia.
- Intentional native-only oil, flame and effect textures remain in the mods.
- Normal and specular alpha channels contain material data and are preserved.
- A non-aliased physical fallback ZIP remains available for older mod builds.
